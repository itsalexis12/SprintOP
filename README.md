# FriendlyEats - FastAPI & Firestore (Sprint 1)

Sistema web para la gestión e interacción con restaurantes desarrollado con **FastAPI**, **Jinja2** y **Google Cloud Firestore Emulator**.

## 🚀 Requisitos Previos

- Python 3.10+
- Node.js & npm (para Firebase CLI)
- Firebase CLI instalado (`npm install -g firebase-tools`)
